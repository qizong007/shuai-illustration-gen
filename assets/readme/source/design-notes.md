# README hero

Audience: authors and makers who need consistent editorial illustrations.
Value: turn a topic into a conceptual paper-collage illustration.
Visual metaphor: a pencil stroke becomes a bird with one vermilion wing.
Canvas: 1200 x 420, matching the shuai-cover-resize README hero ratio.
Palette: ivory #FBF8F1, ink #171717, paper #F7F5EF, gray #BDB9B0, red #D32918.

The artwork was newly generated with the built-in image_gen tool. The exact prompt is in hero-art.prompt.txt. SVG provides editable typography and layout; PNG is the published asset. These files serve only the README, not the skill's runtime instructions.

Render from this directory:

```bash
rsvg-convert --width 2400 --height 840 hero-layout.svg --output ../hero.png
```
